# Smart File Search Engine

A Java-based desktop application that allows users to quickly search and locate files using a simple and user-friendly graphical interface.

## Features

* 🔍 Search files by name or keyword
* 📁 Search across different file types
* 🔽 File type filtering
* 🕒 Search history
* 🖥️ Simple and user-friendly GUI
* ⚡ Fast file searching
* 📄 Organized search results

## Technologies Used

* **Java**
* **Java Swing**
* **File I/O**
* **Object-Oriented Programming**
* **Collections Framework**

## Project Structure

```text
src/
├── META-INF/
│   └── MANIFEST.MF
├── FileSearchGUI.java
└── Main.java
```

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Make sure Java/JDK is installed.
4. Run `Main.java`.
5. Enter a search keyword and select the required file type.
6. Click **Search** to find matching files.

## Purpose

This project was developed to practice **Java desktop application development, GUI design, file handling, search functionality, event handling, and object-oriented programming**.
